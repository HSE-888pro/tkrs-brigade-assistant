# Цифровой ассистент бригады · ТКРС

Офлайн-инструмент для мастеров и инженерно-технического персонала капитального ремонта скважин.  
Реализует единый стандарт бережливого производства в формате интерактивного чат-бота.

## 🎯 Назначение

Приложение предназначено для использования на промышленных планшетных терминалах в полевых условиях (кустовые площадки, буровые), где отсутствует стабильное интернет-соединение.

## ✨ Возможности

- 🛡 **Критичные барьеры** — 6 СТОП-правил, стандарты СЗВТ, работы на высоте, грузоподъёмные операции
- 📋 **Интерактивные чек-листы** — готовность вахты, стропы, СИЗ (с сохранением прогресса)
- 🎙 **Голосовые сценарии планёрок** — утренняя (07:30) и вечерняя (19:30) с таймером обратного отсчёта
- 📊 **Озвучка метрик** — формирование и голосовое воспроизведение отчёта по KPI вахты
- 💡 **Кайдзен-уроки** — 12 формул поведения с функцией «случайный урок» для планёрки
- 🧹 **Стандарт 5S** — чек-листы аудита рабочего места
- 🏆 **Рейтинг бригады** — шкала премирования и стоп-факторы

## 🛠 Технологии

- **Vanilla JavaScript** — без фреймворков и внешних зависимостей
- **Single-File Architecture** — весь код в одном `index.html`
- **Offline-First** — работает без интернета (CSP: `connect-src 'none'`)
- **Web Speech API** — синтез речи на русском языке
- **Web Audio API** — звуковые эффекты интерфейса
- **localStorage** — сохранение состояния чек-листов

## 🔒 Безопасность

- **XSS Protection** — пользовательский ввод обрабатывается через `textContent`
- **Content Security Policy** — строгий CSP в мета-теге
- **Kiosk Mode** — блокировка F12, Ctrl+Shift+I/J/C, Ctrl+U/S/P для промышленных устройств
- **Safe Storage Fallback** — автоматический откат в память при недоступности localStorage

> ⚠️ `unsafe-inline` в CSP — осознанный компромисс для single-file архитектуры без сборщика.  
> Для production-развёртывания с внешним JS рекомендуется перенести CSP на HTTP-заголовки сервера.

## 🚀 Локальный запуск

Просто откройте `index.html` в любом современном браузере (Chrome, Edge, Safari, Firefox).  
Никаких серверов, сборок или установок не требуется.

## 🌐 Развёртывание на GitHub Pages

1. Создайте публичный репозиторий
2. Загрузите `index.html` в корень
3. Settings → Pages → Source: `main` branch → `/ (root)`
4. Приложение будет доступно по адресу `https://<username>.github.io/<repo>/`
